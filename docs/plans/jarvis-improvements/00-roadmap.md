# Дорожная карта улучшений Jarvis (с 2026-09-27)

16 идей не влезут в один цикл гейтов (диф на тысячи строк, не отревьюить).
Поэтому они разбиты на 6 итераций. У каждой итерации своя папка
`docs/plans/<slug>/` и полный цикл software-factory (4 гейта → слайсы).
Следующая итерация начинается после того, как предыдущая выкачена и
проверена вживую.

Порядок выбран так: сначала цифры (метрики), потом то, что даёт эффект в
каждой реплике, потом надёжность, потом новые возможности. То, что зависит
от внешних вещей (записи голоса, железо умного дома), идёт в конце.

| # | Итерация (папка) | Что входит | Зачем именно здесь |
|---|------------------|------------|--------------------|
| 1 | Быстрее (`it1-faster`) | метрики задержки; потоковая озвучка (говорит с первого предложения); пометка «прервано» и замер перебивания (само перебивание в вебе уже есть); новые быстрые команды (время, дата, погода, «какие таймеры») | каждая реплика; метрики нужны, чтобы доказать остальное |
| 2 | Надёжнее (`it2-reliable`) | healthcheck с пушем в Telegram (сервисы, RAM/своп); автопереход на локальную LLM при 401/402/таймауте облака + голосом «я в офлайн-режиме»; тесты `mcp_server` и `timers` | ключ LLM уже ломался дважды; RAM — главный риск |
| 3 | Помнит (`it3-memory`) | память фактов о семье (запомни / что ты знаешь про…); уточняющий вопрос вместо «не нашёл» при неуверенном поиске; сказки с продолжением | делает своего агента полезным без Hermes |
| 4 | Быт (`it4-daily`) | повторяющиеся напоминания (будни, каждый день, по дням недели); утренний брифинг по будильнику (погода, дела, музыка); экран «Сегодня» в PWA | опирается на итерации 1–3 (быстрые команды, память) |
| 5 | Уши (`it5-wakeword`) | своё русское «Джарвис» для слушателя на asus + перебивание ответа там (listener сейчас выключен) | нужны ~20–50 записей твоего голоса и домашних |
| 6 | Дом и тексты (`it6-home-lyrics`) | умный дом; поиск песни по словам («найди песню со словами…») | умный дом — только после ответа, какие устройства есть |

## Открытые вопросы (понадобятся к своим итерациям)

- Ит. 5: кто будет говорить «Джарвис» (голоса для записи)?
- Ит. 6: какие устройства умного дома есть (Яндекс, Home Assistant, Xiaomi…)? Если нет — пункт вычёркиваем.
