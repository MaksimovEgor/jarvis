# Slices: Яндекс Музыка

1. **Tracer — подключение.** `yandex.py`: токен, код устройства, фоновый опрос, статус;
   `/library/yandex/*`; карточка в «Моей музыке». Итог: ты подключаешь аккаунт, карточка
   показывает логин и Плюс. (нужен пакет yandex-music)
2. **Играть из Яндекса.** `sources.py` (resolve + match_score + is_song + download), MP3 320,
   `/media/file/<ref>`, плеер/выходы через фасад. «Включи Кино» играет из Яндекса, чего нет — YouTube.
3. **FLAC и лайки.** lossless через get-file-info (+AES, +ремукс), лайк → Яндекс + FLAC в liked/,
   импорт лайков Яндекса, «включи мои лайки» из обоих. Бейдж «FLAC · 16 бит / 44,1 кГц».
4. **Волна Яндекса.** корзина yandex, настроения → rotor settings, фидбек старт/дослушал/пропуск,
   похожие через rotor track:<id>.
5. **SoundCloud + калибровка совпадений** на реальных запросах; «нет в Яндексе» в плеере.
6. **Метрика по источникам, доки** (architecture.html, README), неделя замеров.
