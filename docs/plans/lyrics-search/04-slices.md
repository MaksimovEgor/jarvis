3. **Поиск: Яндекс / YouTube / SoundCloud** — catalog.py, `/library/search`, play_entity (трек, исполнитель,

4. **Книги / Подкасты / Детям** — вкладки, главы по порядку с места остановки, подкаст с последнего выпуска,
   детские станции + фильтр жанров.
5. **Голос и доки** — «покажи текст», книги/подкасты голосом из Яндекса, MCP show_lyrics, architecture.html.
