# Slices: Музыкальная библиотека и «Моя волна»

Каждый слайс заканчивается рабочим состоянием, деплоем на asus и проверкой руками.

1. **Tracer bullet — ♡/👎 насквозь.** Кнопки в PlayerBar → `POST /library/rate` (оценка в памяти,
   без БД) → SSE-снимок `rating` → сердечко закрашено; «лайк»/«дизлайк» голосом через router
   отвечают заглушкой. Видно на телефоне.
2. **Настоящие лайки и хранилище.** `library.py` (SQLite) + `storage.py` (liked/ ↔ cache/, лимит
   10 ГБ − лайки), дизлайк переключает трек и удаляет файл, `/library/storage`. pytest +
   `requirements-dev.txt`, тесты library/storage/player_rating.
3. **Журнал прослушиваний и метрика.** start/finish play, пропуск vs дослушал, `from`
   (liked/cache/net), `start_ms`, `/library/stats`. Чипы «кэш/сеть/♥ сохранено» в плеере.
4. **Волна v1 без LLM.** `wave.py` (`compose`, слоты, баны, штрафы, ARTIST_GAP), корзины
   liked + similar (YouTube Mix), `play_wave`, `play_liked`, фразы router + MCP. Тесты wave/router.
   С этого слайса «включи музыку» работает.
5. **Профиль Hermes dj.** Настройка на asus (`scripts/hermes-dj/`, юнит :8643), `taste.py`:
   зёрна → корзина discover, разметка энергии/жанра → энергия под слот и настроение,
   запасной путь через LLM. Тесты taste.
6. **Стабильность.** Сторож зависаний (браузер `waiting` > 10 с + серверный 25 с), таймаут
   загрузки 25 с, офлайн-режим волны (только liked/cache), «застрял» в журнале.
7. **Экран «Моя музыка».** MyMusic.vue: карточка волны с настроениями, лайки (пагинация, поиск),
   скрытые с «Вернуть», шкала места; RateToast с «Отменить»; `play_ref`.
8. **Dj учится.** Суточная сводка в 04:00, `music_taste_note`, `now_playing` «из твоих лайков»,
   `VOICE_INSTRUCTIONS`, мягкий перезапуск gateway Hermes под новые MCP-инструменты.
9. **Доки и неделя метрики.** `docs/architecture.html`, README; через неделю — `/library/stats`
   против цели (≥ 70% дослушано, 0 зависаний).
