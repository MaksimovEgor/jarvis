# Jarvis — правила для агентов

Общий файл для всех агентов (Claude Code, Hermes и др.). `CLAUDE.md` только импортирует его.

## Команды и проверка

- Код правится на Mac, работает на asus (`~/jarvis`). Выкатка: `./scripts/deploy.sh`
  (`SKIP_PIP=1` — если зависимости не менялись). Правки прямо на asus затрёт rsync.
- Тесты — на asus (локального `.venv` нет):
  `rsync -az app tests asus:jarvis/ && ssh asus 'cd jarvis && nice .venv/bin/pytest -q'`.
- Фронт (`web/`): `npm run typecheck`, `npm run build`.
- После выкатки: `ssh asus 'systemctl --user is-active jarvis-core jarvis-tts jarvis-llm'`.
- Работа не считается сделанной без зелёных тестов и живых сервисов — покажи вывод.
- После фичи обнови `docs/architecture.html`.

## Сервер asus — ограничения

- RAM 5,8 ГБ — узкое место. Перед загрузкой моделей и тяжёлыми замерами: `free -m`;
  не грузить вторую копию модели рядом с работающими сервисами — уйдёт в своп.
- GPU GTX 1050 (2 ГБ) — только по требованию (jarvis-llm/Ollama, воркер расшифровки).
- LLM-провайдер не хардкодить: в конфигах `main`/переменные, не имена провайдера.
- Hermes (`~/.hermes`) — вне git. После новых MCP-инструментов gateway мягко перезапускается `kill -USR1`.

## Координация параллельных агентов (обязательно)

Над проектом могут работать несколько агентов одновременно в одном рабочем каталоге.
Чтобы не конфликтовать, используется «доска объявлений» — `AGENT_STATUS.md` в корне.

Протокол:

1. **Перед любым действием** (правка файлов, рестарт сервисов, git-операции) прочитай `AGENT_STATUS.md`.
2. **Заяви работу**: добавь строку в таблицу «Активные агенты» — id сессии/имя, задача, ветка, **файлы/каталоги**, **сервисы**, которые будешь менять/перезапускать, время начала.
3. **Проверь пересечения**: если твои файлы/сервисы/ветка пересекаются с заявкой соседа — НЕ начинай. Возьми другую часть работы или спроси пользователя.
4. **После каждого завершённого шага** обнови свою строку (статус, что уже изменено).
5. **По завершении** перенеси строку в «Завершено» (кратко: что сделано) и освободи файлы/сервисы.
6. Строки старше ~2 часов без обновления считай устаревшими — уточни у пользователя, прежде чем игнорировать.

Дополнительно:
- Не делай `git add -A`, `git stash`, `git checkout .`, `git reset` — это затрагивает чужие незакоммиченные правки. Добавляй в коммит только свои файлы явно. (Для Claude Code это ещё и заблокировано хуком в `.claude/settings.json`.)
- Перезапуск общих сервисов (Hermes/MCP, docker, web player :8643 и т.п.) — только если сервис не заявлен соседом.
- `AGENT_STATUS.md` не коммитится (в `.gitignore`) — это локальное состояние.
- Для полной изоляции предпочитай `git worktree` (отдельный каталог и ветка на агента).
